Aurora is the official HOPE online registration tool. It is released as an open source project, feel free to contribute and use it.

It has been developed with performance and security as its main key points.

The strengths of Aurora are:

- Incredibly fast (reached 15.000 registrations per second)
- Security (supports data encryption at rest and in transit)
- Powerful form builder
- Support complex validation logic
- Database level user defined per form unique keys
- Multilanguage
- Open and protected online registrations
- Straightforward architecture
- Custom form page (partner logos, header, footer, colors...)
